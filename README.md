# 🎂 Convite de 17 Anos — Samira

Convite digital desenvolvido para comemorar meus 17 anos, com uma proposta minimalista e delicada em tons de azul, prata e branco.

## 🔗 Demonstração
> **Acesse aqui:** <br>(https://samiratoledo.github.io/aniversario17/) 

## ✨ Sobre o projeto

O convite apresenta:

- 📅 Data, horário e local da festa
- 🎁 Guia de presentes
- 📚 Sugestões de presentes e vale-presentes
- 💳 Chave Pix com botão para copiar
- 📱 Layout responsivo para celular e computador
- ✨ Animações e detalhes visuais

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🎨 Estilo

O projeto utiliza uma estética minimalista e editorial, com:

- Azul, prata e branco
- Tipografia serifada e monoespaçada
- Layout responsivo
- Animações suaves
- Elementos decorativos sutis

## 📱 Responsividade

O convite foi desenvolvido para funcionar em diferentes tamanhos de tela, especialmente em dispositivos móveis.
